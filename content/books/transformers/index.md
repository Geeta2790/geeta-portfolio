Transformers are the architecture behind every modern language model: GPT, Claude, Gemini, Llama, Mistral. If you work on anything LLM-adjacent, understanding what's happening inside the box pays off quickly - it changes how you prompt, how you fine-tune, how you reason about failure modes, and how you talk to the model like a system rather than a magic oracle.

This book is a short, intuition-first tour. It is not a replacement for the original *Attention Is All You Need* paper or the Illustrated Transformer. It is the mental model I wish I had on day one, written down.

The chapters build on each other but stay short. Read them in order the first time; refer back later as needed.
